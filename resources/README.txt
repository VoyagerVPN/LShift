LShift 0.1.8 — Windows x64

Запуск: LShift.exe. Значок может находиться под стрелкой скрытых значков Windows.
Для запуска достаточно одного EXE. Для автозапуска сохраните его в постоянной папке.
Правый щелчок: меню. Двойной щелчок: настройки.

Два коротких нажатия левого Shift исправляют выделенный текст или недавно набранное слово
в поддерживаемом текстовом поле и переключают раскладку. Нужны стандартные
English US QWERTY и Русская ЙЦУКЕН. Пустое поле/числа: только смена языка.

Недавно набранное слово проверяется по короткому журналу клавиш и текущему тексту
поля. Удаление и исправленный ввод отправляются одним пакетом без выделения и пауз.
Нажатия мыши, навигация и смена фокуса сбрасывают журнал. Без подтверждённого
слова жест только меняет язык. Отмена слова может потребовать нескольких Ctrl+Z.
Редактор может показать промежуточный текст между удалением и вводом.

Большое пользовательское выделение заменяется одной вставкой целого фрагмента.
В 0.1.6 каждое слово выделения преобразуется отдельно: привет ghbdtn → ghbdtn привет.
Смешанное внутри слово (приvet) сохраняется целиком, цифры не определяют язык.
Пробелы, дефисы и переносы разделяют слова. Знаки на буквенных клавишах входят
в слово: ;bdjq → живой. Отдельные знаки без букв не преобразуются.
После исправления включается раскладка последнего преобразованного слова.
В этом сценарии буфер содержит исправленный текст; восстановления нет.
История Windows открывается через Win+V. Адаптеров для отдельных приложений нет.

В 0.1.3 исправлен отказ обратного преобразования после других набранных слов.
В 0.1.4 чтение контекста ограничено границами самого поля.
В 0.1.5 исправлен повторный набор после Ctrl+A → Backspace/Delete.
Пауза между набором и двойным Shift не ограничена таймером.
В 0.1.7 из обычной сборки исключены файловый журнал и диагностическая очередь.
COM подготавливается только перед первой текстовой командой. Фоновый worker
ожидает команды без таймера опроса. Название в свойствах EXE — LShift.
Значки встроены для размеров от 16 до 256 пикселей.

Настройки: включение/пауза, интервал двойного Shift, длительность нажатия,
автозапуск при входе в Windows. Настройки хранятся в LOCALAPPDATA\LShift.
Автозапуск изначально выключен; включайте после выбора постоянной папки EXE.

Причина последнего результата видна при наведении на значок. При неизвестном
поле, пароле, read-only или изменившемся контексте программа отказывается от записи.
Оба Shift остаются видны приложению: его собственный hotkey тоже может сработать.

Результаты проверок опубликованы в docs/VALIDATION.md исходного проекта.
Текущие Discord/Telegram, физический жест, меню реальной панели Explorer
и игровые времена кадров требуют отдельной проверки.
Перед проверкой завершите другой переключатель,
использующий тот же жест. Автозапуск и другие программы автоматически не менялись.

Выход: меню трея → Выход.
